#  Chart Source Code
 
This repository contains the code used to generate the charts published on the Instagram account [@statisticscolombia](https://www.instagram.com/statisticscolombia/).
 
It is part of the broader [Statistics on Colombia](https://github.com/Andres-pixel35/Statistics_on_Colombia) project.
 
---
 
## Repository Structure
 
The repository is organized by month, then by week. Each week contains a script per each chart published in that week with the chart-generation code and a folder with the data used.
 
```
.
├── YYYY-MM/                  # Month (e.g. 2025-05)
│   ├── week_1/
│   │   ├── MM-DD.ipynb         # Code to generate the charts (e.g. 05-25.ipynb)
│   │   └── data/               # Data used for that week's charts
│   ├── week_2/
│   │   ├── MM-DD.ipynb
│   │   └── data/
│   ├── week_3/
│   │   ├── MM-DD.ipynb
│   │   └── data/
│   └── week_4/
│       ├── MM-DD.ipynb
│       └── data/
```
